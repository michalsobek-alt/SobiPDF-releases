# SobiPDF

Szybki podgląd i wizualna edycja PDF dla Windows, autorstwa **SobekAI Studio**.
Autor: **Sobek**. Stworzone z pomocą **Codex**.

[Pobierz najnowszą wersję](https://github.com/michalsobek-alt/SobiPDF-releases/releases/latest)

## Instalacja

Pobierz plik `SobiPDF-Setup-0.8.1.exe` z najnowszego wydania i uruchom polski kreator.
To jeden plik instalatora z kompletną aplikacją i modułem kompresji.
Skojarzenie PDF jest domyślnie zaznaczone. Po instalacji potwierdź wybór
SobiPDF w ustawieniach aplikacji domyślnych Windows.

## Aktualizacja z programu

1. Otwórz **Ustawienia → Aktualizacje → Sprawdź teraz**.
2. Wybierz **Pobierz aktualizację**.
3. Zamknij wszystkie okna SobiPDF i ponownie otwórz PDF.

Po udanej aktualizacji program jednorazowo pokaże poprzedni i nowy numer wersji.
Ustawienia i dokumenty pozostają zachowane.

Pozdrawiamy **Mikołaja — testera SobiPDF!**
